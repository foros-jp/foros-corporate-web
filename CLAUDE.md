# FOROS Corporate Website

## Overview
FOROS株式会社のコーポレートサイト。Astro + Tailwind CSS v4 で構築。
GitHub Pages でホスティング（0円運用）。

**Mission:** お客様の競争力を最大化し、お客様と共に成長する — Accelerating Competitiveness.

## Tech Stack
- **Framework:** Astro 5.x (Static Site Generator)
- **Styling:** Tailwind CSS 4.x (CSS-first config via `@theme`)
- **Hosting:** GitHub Pages (custom domain: foros.jp)
- **CI/CD:** GitHub Actions (push to main → auto build → deploy)

## Commands

- `npm run preview` — Preview production build locally

## Design System

### Brand Colors (Light theme)
- **Surface:** `#ffffff` (white)
- **Surface Alt:** `#eef0f5` (light gray, section backgrounds)
- **Primary:** `#c97a15` (brand orange — WCAG AA compliant on white)
- **Accent:** `#1b3a6b` (brand navy)
- **Emerald:** `#047857` (success/highlight)
- **Muted:** `#64748b` (secondary text — 4.76:1 contrast ratio)
- **Border:** `rgba(0,0,0,0.15)` / hover: `rgba(0,0,0,0.25)`

### Logo
Hexagon cluster: orange top hex (#E8891A) + 2 navy bottom hexes (#1B3A6B). "FOROS" text in `#C97A15`.

### Typography
- **Body:** Inter + Noto Sans JP (sans-serif)
- **Code/Accents:** JetBrains Mono (monospace)

### Animations & Interactions
- **Scroll-triggered:** `.anim` (fade up), `.anim-left` / `.anim-right` (slide in), `.stagger` (children delay)
- **Micro-interactions:** `.cta-pulse` (CTA glow), `.story-icon` (hover bounce), `.svg-draw` (stroke draw + hover glow)
- **Containers:** `.card` / `.card-glow`, `.glass` / `.glass-hover`
- **Text:** `.gradient-text` (primary→accent gradient)
- **Parallax:** `data-parallax` attribute on Hero orbs (JS scroll listener)
- All animations respect `prefers-reduced-motion`

### Icons
Heroicons outline style (stroke-width 1.5) throughout: Stories/Achievements cards, About dt labels, Contact form labels, Footer nav links.

## Accessibility
- WCAG AA contrast ratios verified (4.5:1 normal text, 3:1 large text/UI)
- `prefers-reduced-motion` respected for all animations
- Skip navigation link (`.skip-nav`)
- `:focus-visible` outlines on interactive elements
- Semantic HTML5 sections with proper heading hierarchy
- `aria-label` / `aria-expanded` on mobile menu toggle

## SEO
- JSON-LD structured data (Organization)
- OGP & Twitter Card meta tags
- Auto-generated sitemap via @astrojs/sitemap
- Semantic HTML5 sections
- Custom robots.txt

## Security
- **Branch protection** on `main`: PR required, 1 review minimum, status checks enforced, no force push
- **CODEOWNERS:** All files require approval from `@alessandrogoto` or `@qualiatokyoltd`
- Public repository — no secrets in code

## Deployment
Push to `main` branch triggers GitHub Actions workflow:
1. Checkout → Node 22 → npm ci → npm run build
2. Upload `dist/` as Pages artifact
3. Deploy to GitHub Pages

Direct push to `main` is blocked; changes must go through PR with admin approval.
